# WASHCLUB — dashboard-style auto detailing demo

A single-file, responsive portfolio concept using baby blue, black and white. Includes a fixed desktop navigation rail, split hero, interactive vehicle/package estimator, horizontally scrollable gallery, and compact dashboard cards.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. In Settings > Pages, choose Deploy from a branch > main > /(root).
3. Wait for the deployment workflow to finish.

## Before using for a real client
- Replace fictional branding and example prices.
- Replace externally hosted Unsplash imagery with licensed client photography.
- Replace `demo@example.com` in the HTML/JS with the client's real email or booking integration.
- Add real contact details, legal notices, and service areas.

The sample pricing is illustrative. This site is a portfolio demo, not a functioning detailing business.
